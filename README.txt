TRAK SALON - PHONE-FRIENDLY PROTOTYPE

How to use:
1. Extract the ZIP file.
2. Open index.html in a web browser.
3. The prototype stores data on that device/browser.

Included:
- Basic, Business and Pro plans
- 7-day Pro trial
- Shipment creation and status updates
- Buyer collection confirmation
- Seller verification
- Owner dashboard
- Demo subscription revenue tracking

Important:
This is a working local prototype, not yet a live commercial app.
Real Orange Money/Afrimoney payments, user accounts, cloud database,
GPS/carrier tracking, notifications, security, and app-store publishing
require backend/API integration and provider approval.
